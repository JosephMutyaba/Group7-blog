About ECMSS

A tech-driven solution designed to improve the quality of care for elderly individuals.

With Uganda's elderly population facing increasing healthcare challenges, ECMSS provides a comprehensive solution. By integrating wearable technology, mobile apps, and web dashboards, the system bridges the gap between caregivers, health professionals, and the elderly — delivering real-time data, alerts, and peace of mind.

Key Features

ECMSS offers a comprehensive suite of features to ensure elderly care and safety

GPS Tracking

Real-time location monitoring to ensure the safety of the elderly, with geofencing capabilities to alert caregivers if boundaries are crossed.

Health Vitals Monitoring

Continuous monitoring of temperature, heart rate, and SpO₂ levels to ensure early detection of health issues.

Medication Reminders

Timely audio and visual reminders for medication schedules, ensuring proper adherence to prescribed treatments.

Caregiver Dashboards

Intuitive web and mobile interfaces that provide real-time insights into the elderly's condition and activity.

Audio Alerts

User-friendly audio notifications designed specifically for elderly individuals with varying levels of tech familiarity.

Motion Detection

Advanced sensors to detect falls, prolonged inactivity, or unusual movement patterns that may indicate distress.

Project Architecture

A comprehensive system designed with multiple integrated components

1. Wearable Device

  • ESP32-based, GSM-enabled
  • Sensors: Temperature, Heart Rate, SpO₂, Motion, GPS
  • Real-time communication with server

2. Progressive Web Application

  • Caregiver dashboard
  • Accessible from desktop or pinned tablets
  • Configurable alerts and reports

3. Mobile Application

  • Optimized for audio reminders and alerts
  • Supports background notifications
  • Simple, elderly-friendly UI
