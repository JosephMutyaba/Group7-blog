About Me

A final-year Software Engineering student at Makerere University specializing in mobile and backend development. My work is grounded in building impactful digital health systems that are both user-friendly and scalable. I thrive at the intersection of embedded systems, healthcare, and mobile technology.

As part of the ECMSS project, I led the development of the Android mobile application that was specifically created to solve a core system limitation—ensuring medication reminders reach the elderly even when the Progressive Web App (PWA) is not actively open. I worked on foreground notification handling, voice-based alerts, and seamless interaction for caregivers and patients.

Contribution to ECMSS

Mobile Application Development

2024-2025 React Native/Expo

Developed the ECMSS Android mobile application from scratch using React Native and Supabase. This application was introduced to address limitations with background notifications in PWAs, and offers:

  • Persistent audio reminders with Take, Snooze, and Later options that automatically update the backend schedule
  • Voice-based alerts optimized for elderly users with low literacy or visual impairments
  • Foreground services that prevent alert disruptions when the app is minimized
  • Secure login and real-time dashboard for monitoring vitals
  • Device data linking through unique device IDs

Backend Services Integration

2024-2025 Supabase/JavaScript

Collaborated on backend API design and integration logic that connected the wearable device, mobile app, and Supabase backend. My tasks included:

  • Creating Supabase functions and row-level security for mobile-triggered actions
  • Implementing timestamp-based reminder scheduling and status tracking
  • Building notification dispatch logic triggered by backend flags
  • Integrating background synchronization for offline scenarios
